# 来源人脸拓扑校准

本目录按 topology family + digest 保存一次性校准数据。当前 G2F、G2M 文件均为候选证据，所有语义为 **unverified**，不能用于正式身份拟合。两族均未提供已验证的精细语义表；相同连接摘要不能代替 topology_family 校验。

Morph 元数据用于发现候选；真实 support、材质边界和 canonical 一次性确认共同建立语义。候选 support 不等于有序语义曲线，不按人物空间坐标、Preset ID 或人物名补齐缺失项。

操作、数据格式、官方 API 与尚未完成部分见 `../../FACE_FIDELITY.md`。canonical 坐标和离线 OBJ 只在本机 Saved 目录；本文件夹不收录 VaM 原始网格、贴图、Morph delta、付费插件代码或库。
