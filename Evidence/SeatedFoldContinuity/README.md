Root: `VamGluteCorrectiveBuilder::Build` multiplies source/procedural pre-skin fields by target and blended-pose per-vertex safety factors. These factors prevented inversion but could vary abruptly between neighboring vertices. Three right-glute diagnostic edges were smooth before safety (17.62/3.34/0.89 degrees), and became 91.80/84.87/87.88 degrees in the actual final mesh. Source/procedural/residual decomposition matches the posterior actual displacement within 0.000097 cm. The legacy full-body B2 report rejects its total reconstruction because it excludes the separate Knee morph fields; that failure is retained, not bypassed.

Repair: `ContinuousAttenuation` computes a conservative geodesic attenuation envelope on actual mesh edges and proven source aliases. The joint safety loop alternates this with all existing triangle/edge/independent-axis/blended-pose checks. Zero-displacement vertices do not spuriously prolong convergence. No source vertex ID, side, preset, or pose is hard-coded in the repair. The `continuous_safety` policy is explicit in the preserved family recipe. It changes offline baking only. The stable historical configuration is not overwritten; load the new normal BP/configuration from provenance.json.
